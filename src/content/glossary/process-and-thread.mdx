- **프로세스**: 실행 중인 프로그램 하나입니다. OS가 프로그램을 실행할 때마다 다른 프로그램과 섞이지 않도록 메모리 공간을 따로 내줍니다.
- **스레드**: 프로세스 안에서 코드를 실제로 한 줄씩 실행하는 흐름입니다. 프로세스 하나에 스레드가 여러 개 있을 수 있습니다.

OS에는 이런 규칙이 있습니다.

> **같은 프로세스 안의 스레드들은 그 프로세스의 메모리를 공유하고, 스택만 각자 가진다.**

<ProcessThreads />

자바에서는 **`java` 명령 1번 = 프로세스 1개 = [JVM](#term-jvm) 1개**입니다.

- 같은 JVM 안의 스레드들은 **자바 힙(객체)을 공유**합니다. 그래서 같은 객체를 동시에 고치면 [경쟁 조건](#term-race-condition)이 생깁니다.
- 지역 변수는 각 스레드의 **스택**에 있어서 서로 보이지 않고, 그래서 안전합니다.
- **다른 JVM(프로세스)끼리는 메모리가 완전히 분리**되어 있습니다. 서로의 객체를 볼 수 없고, 데이터를 주고받으려면 네트워크나 파일을 거쳐야 합니다.

Spring Boot 서버 하나를 띄우는 것도 java 프로세스 하나를 띄우는 것입니다. Tomcat 스레드 200개가 모두 이 프로세스 **안에서** 같은 힙을 공유하며 돌아갑니다.
